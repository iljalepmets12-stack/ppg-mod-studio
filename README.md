## 📖 О проекте

**PPG Mod Studio** — это интерактивная веб-среда разработки (IDE), доступная прямо в браузере. Инструмент разработан специально для мододелов **People Playground (PPG)** и совмещает в себе визуальный редактор ресурсов, VFS-менеджер файлов и AI-генератор C#-скриптов с поддержкой умных моделей и режимом планирования (Think Mode).

Проект полностью открыт и свободен для любых изменений, доработок и кастомизации. Вся работа происходит прямо на сайте без необходимости установки сторонних программ.

🚀 **[Запустить PPG Mod Studio в браузере](https://iljalepmets12-stack.github.io/ppg-mod-studio/)**

## ✨ Возможности

### 🛠️ Редактор модов & AI-Ассистент
- **Генерация C# и mod.json**: Автоматическое создание виртуальной файловой системы (VFS) мода по текстовому описанию.
- **Интеграция LLM**: Поддержка моделей `gemini-2.5-flash`, `gemini-2.5-pro` и кастомных API через OpenRouter.
- **Режим пошагового планирования (Think Mode)**: AI сначала формирует краткий план разработки, а затем генерирует исходный код.
- **Прикрепление файлов и изображений**: Возможность передавать скриншоты или референсы прямо в чат с ассистентом.

### 📦 Управление проектами
- **Экспорт в ZIP**: Быстрое скачивание готовой структуры мода (`.cs`, `mod.json` и др.) в один клик.
- **Интерактивный предпросмотр**: Просмотр и редактирование файлов мода во встроенной панели.
- **Локальное сохранение**: История чата и созданные файлы автоматически сохраняются в браузере (`localStorage`).

### 🎨 Интерфейс
- **Современный UI/UX**: Тёмная тема в стиле профессиональной IDE.
- **Адаптивный дизайн**: Удобное переключение между панелями чата, файлов и предпросмотра.

## 💡 Как создать первый мод

1. Перейдите на сайт **[PPG Mod Studio](https://iljalepmets12-stack.github.io/ppg-mod-studio/)**.
2. Нажмите на иконку **⚙ (Настройки)** и укажите ваш **API Key** (Gemini / OpenRouter).
3. В поле ввода опишите механику мода, например:
   > *"Создай мод на огненный меч, который поджигает объекты при ударе."*
4. Включите переключатель **🧠 Think**, чтобы AI составил план перед генерацией.
5. Отправьте запрос (**Ctrl + Enter**).
6. Проверьте сгенерированные файлы в панели **📁 Файлы мода** слева.
7. Нажмите **📦 ZIP**, чтобы скачать готовый архив и поместить его в папку `Mods` игры PPG!
