## 📖 О проекте

**PPG Mod Studio** — это среда для разработки модов, которая упрощает создание, тестирование и упаковку пользовательских модификаций для игры **PPG**.

> ⚠️ **Важно:** Проект на ранней стадии разработки. API и функциональность могут меняться.

### 🚀 Ключевые возможности (в плане)
*   **Шаблоны модов** — быстрый старт с готовыми структурами.
*   **Визуальный редактор** — создание контента без глубокого знания кода.
*   **Сборщик проекта** — автоматическая компиляция и упаковка мода в готовый к установке файл.
*   **Превью** — быстрая проверка мода в тестовом окружении.
